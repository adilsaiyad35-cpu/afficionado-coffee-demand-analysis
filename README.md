# Afficionado Coffee Roasters – Demand Analysis

## Project Overview
This project analyzes coffee sales transactions using Python, Pandas, and Streamlit. It helps explore hourly demand patterns, store-wise sales performance, product categories, and peak demand periods.

## Objectives
- Analyze overall sales and revenue.
- Identify peak demand hours.
- Compare sales performance across stores.
- Analyze product categories and top-selling products.
- Explore demand patterns by store and hour.
- Provide an interactive dashboard for business analysis.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Streamlit
- Matplotlib
- Seaborn

## Dashboard Features
- Business overview and key metrics
- Hourly demand analysis
- Store-wise sales analysis
- Product category analysis
- Top 10 products
- Peak demand by store
- Store and hour heatmap
- Hourly demand profile
- Interactive filters
- Downloadable CSV reports
- Raw transaction data view

## Dataset
The project uses the Afficionado Coffee Roasters transactions CSV dataset.

The available dataset does not contain a complete transaction date suitable for building a reliable daily time series. Therefore, this version focuses on historical sales and hourly demand analysis rather than claiming verified future forecasts.

## Run the Project Locally

1. Install Python.
2. Install the required packages:

   ```bash
   pip install -r requirements.txt
   ```

3. Keep `app.py`, `requirements.txt`, and the CSV dataset in the same folder.
4. Run the application:

   ```bash
   streamlit run app.py
   ```
